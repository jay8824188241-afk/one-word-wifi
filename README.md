Gaslighting — one word for my Wi-Fi: it swears it is connected, full bars, while nothing loads, and leaves you wondering whether the problem is the router or you. `python3 main.py` writes exactly that one word to `$MAKEFUN_OUTPUT_DIR/entry.txt` (no trailing newline), which is what the bounty gate reads.

## Run it

```sh
python3 main.py
```
